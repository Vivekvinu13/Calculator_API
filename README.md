# Powerful Calculator API

A simple but powerful calculator API built with **FastAPI**.

This project provides basic arithmetic operations, advanced mathematical expression evaluation, mathematical constants, validation, error handling, and interactive Swagger API documentation.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Power / Exponentiation
- Modulo
- Percentage calculation
- Square root
- Mathematical constants
- Advanced mathematical expressions
- Unary operations
- Parentheses and standard mathematical precedence
- Safe expression evaluation without `eval()`
- Division-by-zero validation
- Input validation
- Error handling
- Interactive Swagger UI
- Custom Swagger background color

## Technologies Used

- Python
- FastAPI
- Uvicorn
- Pydantic
- Python AST
- Python `math` module
- Python `operator` module
